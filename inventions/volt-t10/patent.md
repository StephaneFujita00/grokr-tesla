# Hardware comparator verification of RCM low-speed airbag calibration thresholds

## Abstract
A restraint control module (RCM) adds a hardware comparator stage that continuously verifies software-selected low-speed passenger airbag deployment thresholds against a fixed 1.95 V reference derived from a resistor divider and EEPROM. Mismatch exceeding 50 mV for longer than 10 ms asserts a fault line that forces conservative deployment logic, directly correcting calibration table errors identified in NHTSA 22V843000.

## Problem
RCM software calibration tables for frontal crash severity thresholds below 25 km/h can contain incorrect values that cause improper front passenger airbag deployment timing or suppression, violating FMVSS 208. OTA software updates alone leave residual risk from flash corruption or future table drift.

## Summary of the invention
The invention places an LM393 comparator on the RCM board that compares the microcontroller-selected deployment threshold voltage against a 1.95 V reference generated by a 0.5 % resistor divider scaled from a 5 V rail and backed by an EEPROM cell. When deviation exceeds 50 mV for more than 10 ms the open-collector output pulls fault line low, isolating the deployment driver via optocoupler and defaulting to conservative low-speed logic.

## Claims
1. A restraint control module comprising a primary microcontroller executing software calibration tables for passenger airbag deployment thresholds and a secondary verification circuit including an LM393 comparator with reference voltage generated by a resistor divider network having 0.5 % tolerance metal-film components connected to a 5 V regulated supply, wherein the comparator output asserts a fault line if the software threshold deviates more than 50 mV from the 1.95 V reference for longer than 10 ms.
2. The module of claim 1 wherein the 1.95 V reference voltage is stored in a one-time programmable EEPROM cell scaled to represent the 25 km/h low-speed crash threshold and refreshed on power-up.
3. The module of claim 1 further comprising a 100 nF debounce capacitor C1 implementing a 10 ms time constant on the comparator output before fault declaration.
4. The module of claim 1 wherein the primary microcontroller is isolated from the verification circuit by an optocoupler rated for 2.5 kV on the fault line.
5. The module of claim 1 wherein the resistor divider network uses metal film resistors with temperature coefficient of 25 ppm/°C mounted on an alumina ceramic substrate to maintain 0.5 % tolerance over -40 °C to +85 °C.
6. The module of claim 1 wherein the verification circuit is powered from a separate 5 V rail supplied by an independent linear regulator having 1 % output accuracy and 3 mA quiescent current.

## Detailed description
The restraint control module housing (12) contains printed circuit board (14) on which primary microcontroller (16) receives acceleration signals from frontal crash sensor (18). Microcontroller (16) selects a deployment threshold voltage between 1.8 V and 3.2 V according to software calibration tables stored in flash. Reference voltage generator (20) consists of resistor R1 (22) of 10 kΩ ±0.5 % and resistor R2 (24) of 4.02 kΩ ±0.5 % connected across 5 V rail (26) to produce 1.95 V reference corresponding to the 25 km/h threshold; the same value is mirrored by EEPROM cell (20). Comparator (28) type LM393 compares the software threshold voltage applied to inverting input pin 2 against the reference on non-inverting pin 3. When difference exceeds 50 mV the open-collector output on pin 1 pulls fault line (30) low after 10 ms debounce implemented by capacitor C1 (32) of 100 nF connected to ground. Optocoupler (34) rated 2.5 kV isolation couples the fault signal to deployment driver circuit (36) which then forces airbag inflator (38) into conservative low-speed mode. Separate linear regulator (40) supplies the verification circuit from vehicle 12 V battery (42). All components operate over -40 °C to +85 °C with resistor network on alumina substrate (44) to maintain 0.5 % tolerance. In the failure mode of software flash corruption the comparator continuously asserts fault within 2 ms, preventing incorrect low-speed deployment. The circuit adds 8 mm × 12 mm board area and draws 3 mA quiescent current. Every reference numeral used in the claims appears on FIG. 1.
