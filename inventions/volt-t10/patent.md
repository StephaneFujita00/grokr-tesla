# Hardware-based RCM calibration verification for passenger airbag deployment thresholds

## Abstract
A restraint control module (RCM) includes a secondary verification circuit that cross-checks software calibration values for low-speed frontal crash thresholds against fixed hardware references. The circuit uses a comparator and EEPROM-stored reference voltages scaled to 5 V supply with 0.5 % tolerance resistors to confirm deployment decisions within 2 ms of primary processing.

## Problem
RCM software calibration errors can cause incorrect front passenger airbag deployment timing or suppression in low-speed crashes below 25 km/h, violating FMVSS 208. OTA updates alone leave vehicles vulnerable to future calibration drift or flash corruption.

## Prior art
- US11858450B2 Roof-mounted occupant restraint system: describes roof airbag deployment but provides no RCM calibration verification hardware.
- US11059449B2 Roof-mounted occupant restraint system: focuses on airbag geometry, not electronic threshold checking.
- US11345300B2 Roof-mounted occupant restraint system: covers roof airbag kinematics without calibration safeguards.

## Summary of the invention
The invention adds a hardware comparator stage to the RCM that continuously monitors the software-selected deployment threshold voltage against a fixed reference derived from crash severity sensors. If mismatch exceeds 50 mV for more than 10 ms, the module defaults to conservative deployment logic and logs a fault.

## Claims
1. A restraint control module comprising a primary microcontroller executing software calibration for passenger airbag deployment thresholds and a secondary verification circuit including a comparator with reference voltage generated by a resistor divider network having 0.5 % tolerance components connected to a 5 V regulated supply, wherein the comparator output inhibits deployment if the software threshold deviates more than 50 mV from the reference for longer than 10 ms.
2. The module of claim 1 wherein the reference voltage is stored in a one-time programmable EEPROM cell scaled to represent a 25 km/h low-speed crash threshold.
3. The module of claim 1 further comprising a 2 ms debounce timer on the comparator output before fault declaration.
4. The module of claim 1 wherein the primary microcontroller is isolated from the verification circuit by optocouplers rated for 2.5 kV.
5. The module of claim 1 wherein the resistor divider network uses metal film resistors with temperature coefficient of 25 ppm/°C mounted on a ceramic substrate.
6. The module of claim 1 wherein the verification circuit is powered from a separate 5 V rail with independent linear regulator having 1 % output accuracy.

## Detailed description
The restraint control module housing (12) contains a printed circuit board (14) on which primary microcontroller (16) receives acceleration signals from frontal crash sensor (18). Microcontroller (16) selects a deployment threshold voltage between 1.8 V and 3.2 V according to software calibration tables. Reference voltage generator (20) consists of resistor R1 (22) of 10 kΩ ±0.5 % and resistor R2 (24) of 4.02 kΩ ±0.5 % connected across 5 V rail (26) to produce 1.95 V reference corresponding to the 25 km/h threshold. Comparator (28) type LM393 compares the software threshold voltage on pin 2 against the reference on pin 3. When difference exceeds 50 mV the open-collector output pulls fault line (30) low after 10 ms debounce implemented by capacitor C1 (32) of 100 nF. Optocoupler (34) rated 2.5 kV isolation couples the fault signal to the deployment driver circuit (36) which then forces airbag inflator (38) to the conservative mode. Separate linear regulator (40) supplies the verification circuit from vehicle 12 V battery (42). All components operate over -40 °C to +85 °C with resistor network on alumina substrate (44) to maintain 0.5 % tolerance. In failure mode of software flash corruption the comparator continuously asserts fault within 2 ms preventing incorrect low-speed deployment. The circuit adds 8 mm × 12 mm board area and draws 3 mA quiescent current.
